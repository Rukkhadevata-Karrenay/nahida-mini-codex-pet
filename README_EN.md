## Files

- `dist/pet.json` - Codex pet manifest.
- `dist/spritesheet.webp` - 8 x 9 Codex pet spritesheet atlas.

## Install

Copy the `dist` files into your Codex pet folder:

```bash
mkdir -p ~/.codex/pets/nahida-mini-codex-pet-v1
cp dist/pet.json ~/.codex/pets/nahida-mini-codex-pet-v1/pet.json
cp dist/spritesheet.webp ~/.codex/pets/nahida-mini-codex-pet-v1/spritesheet.webp
```

Restart Codex if the pet list does not refresh immediately.

## Package Details

- Pet id: `nahida-mini-codex-pet-v1`
- Display name: `Nahida Mini`
- Atlas size: `1536x1872`
- Cell size: `192x208`
- Format: WebP with transparency
